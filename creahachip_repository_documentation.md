## 🚀 Deployment Guide (GitHub Pages)

To host this portal for free on GitHub Pages:

1. **Fork or Create Repository:**
   - Create a repository named `creahachip` (or your preferred name) on GitHub.
2. **Upload Files:**
   - Add all 4 HTML files (`index.html`, `a1x-crypto.html`, `bank.html`, `citizenship-products.html`) directly into the `main` branch root.
3. **Activate Pages:**
   - Go to **Settings > Pages**.
   - Under **Source**, select `main` branch and `/ (root)` folder.
   - Click **Save**.
4. **Access Portal:**
   - Your site will be live at `https://<your-username>.github.io/creahachip/`.
